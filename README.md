# hackathon

## Play Delta Warp

Download the Windows or Linux archive from the [latest release](https://github.com/ghalrym/hackathon-project/releases/latest). Extract it and double-click `delta-warp.exe` on Windows or `delta-warp.x86_64` on Linux. To host the Web build, extract `delta-warp-web.zip` into a directory served by a web server.

## Publish a build

Push a version tag such as `v0.1.0` to GitHub. The **Release builds** workflow exports all three platforms from that tag and attaches the archives to its GitHub Release.

Created in [T3 Code](https://t3.codes).
